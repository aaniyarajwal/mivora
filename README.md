# 🏠 Mivora

**Find your next place. Feel at home, wherever you go.**

Mivora is a location-based housing discovery platform designed for **students and working professionals** who are moving to a new city and looking for a suitable place to stay.

The platform aims to make finding **flats, houses, and PGs** easier by helping users discover housing options based on their preferred location.

## ✨ Planned Features

* 📍 Location-based housing discovery
* 🏠 Explore flats, houses, and PGs
* 🔎 Search and filter accommodation
* 🗺️ Live location integration
* 📱 Simple and user-friendly interface
* 👤 Designed for students and working professionals
* 🤖 Personalized housing recommendations
* 📏 Distance-based property discovery

## 🛠️ Tech Stack

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/aaniyarajwal/mivora.git
```

### Navigate to the project

```bash
cd mivora
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

The application will be available at the local development URL shown in your terminal.
